# LegalHelp

> **Status: In Progress** — Full release targeted for **2026-06-18**.

A static web platform for generating professional legal documents. No account required, no backend — everything runs in the browser.

---

## Features (completed so far)

- **Homepage** — company overview, services, testimonials, and contact form
- **Agreement Builder** — 3-step wizard to generate one of 4 agreement types, with state-specific legal provisions automatically applied for all 50 US states
  - Non-Disclosure Agreement (NDA)
  - Employment Contract
  - Freelance Agreement
  - Lease Agreement
- **Dashboard** — agreement history (stored in `localStorage`), stats, type/state filters, and quick-create shortcuts

## Tech Stack

- Plain HTML, CSS, JavaScript — no framework
- `localStorage` for client-side persistence
- Google Fonts (Inter + Playfair Display)

## File Structure

```
index.html       Homepage
builder.html     Agreement wizard (3 steps)
dashboard.html   Agreement history & stats
app.js           All builder logic, state provisions, templates
styles.css       Global design system
builder.css      Builder-specific styles
dashboard.css    Dashboard-specific styles
```

## Local Development

```bash
# Serve from the project directory
python3 -m http.server 5500
```

Then open `http://localhost:5500` in your browser.

## Disclaimer

Documents generated by this platform are **templates only** and do not constitute legal advice. Always consult a qualified attorney before executing any legal agreement.
