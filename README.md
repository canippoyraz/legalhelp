# LegalHelp

A web platform for generating professional legal documents. The repo has two versions of the app:

- **`frontend/`** — the current version: a Next.js app with accounts, an AI legal guidance chat widget, and a test suite.
- **Repo root** (`index.html`, `builder.html`, `dashboard.html`, `app.js`) — the original static prototype, kept for reference. No account required, no backend, everything runs in the browser via `localStorage`.

---

## Next.js App (`frontend/`)

- **Homepage, Agreement Builder, Dashboard** — the same 3-step wizard and 4 agreement types as the static version (see below), rebuilt as a Next.js app.
- **Accounts** — email/password sign up and sign in (`/signup`, `/signin`, `/account`). Passwords are hashed with bcrypt; sessions are signed HMAC cookies (`lib/session.ts`), with a constant-time compare and a dummy-hash check on failed logins to avoid leaking which emails are registered.
- **AI legal guidance chat widget** — floating chat on every page, streaming responses from the Claude API (`app/api/chat/route.ts`, model `claude-sonnet-5`). Scoped by a system prompt to plain-English explanations of clauses and the builder itself, never legal advice for the user's specific situation. Falls back to canned rule-based responses (`lib/chatResponses.ts`) if `ANTHROPIC_API_KEY` isn't set.
- **PDF export** — generated agreements can be downloaded as a PDF (`lib/pdfGenerator.ts`, via jsPDF).
- **Test suite** — Vitest + Testing Library, ~180 tests across auth, session handling, the builder, and the chat client (`frontend/__tests__/`). See `frontend/TESTING.md` for the manual test plan.

### Tech Stack

- Next.js 16 (App Router), React 19, TypeScript
- `better-sqlite3` for the user table, `bcryptjs` for password hashing
- `@anthropic-ai/sdk` for the chat widget
- `jsPDF` for document export
- Vitest, Testing Library, and Playwright for testing

### Local Development

```bash
cd frontend
cp .env.local.example .env.local   # set ANTHROPIC_API_KEY and SESSION_SECRET
npm install
npm run dev
```

Then open `http://localhost:3000`. Run tests with `npm test`.

## Static Prototype (repo root)

The original version of LegalHelp — no accounts, no AI chat, no backend.

- **Homepage** — company overview, services, testimonials, and contact form
- **Agreement Builder** — 3-step wizard to generate one of 4 agreement types, with state-specific legal provisions automatically applied for all 50 US states
  - Non-Disclosure Agreement (NDA)
  - Employment Contract
  - Freelance Agreement
  - Lease Agreement
- **Dashboard** — agreement history (stored in `localStorage`), stats, type/state filters, and quick-create shortcuts

### Tech Stack

- Plain HTML, CSS, JavaScript — no framework
- `localStorage` for client-side persistence
- Google Fonts (Inter + Playfair Display)

### File Structure

```
index.html       Homepage
builder.html     Agreement wizard (3 steps)
dashboard.html   Agreement history & stats
app.js           All builder logic, state provisions, templates
styles.css       Global design system
builder.css      Builder-specific styles
dashboard.css    Dashboard-specific styles
```

### Local Development

```bash
# Serve from the project directory
python3 -m http.server 5500
```

Then open `http://localhost:5500` in your browser.
